# 卯很多 質感版（招募網站＋社群商務套件）

| 路徑 | 內容 |
|---|---|
| `index.html` | 質感版招募網站：菜單規格卡、四級套餐比較、快取GO 一日流程、六格品牌、可檢查的食安清單、合作模式、條件與開辦預算、資金試算、緯度招募區域、街邊店、見習與洽談 |
| `img/` | 網站用照片（已壓縮）；`img/src/` 為 Canva 匯出原檔（1680×944、1200×1500） |
| `social/index.html` | 社群商務套件總覽：帳號設定、上線預覽、九宮格與輪播文案、限動、三條商務流程、4 週排程、規範 |
| `social/img/` | 26 張平台尺寸圖：大頭貼、FB 封面、九宮格 p01–p09、品牌輪播 c1–c7、限動 2 款、精選封面 6 個 |
| `social/kit-src.html`、`social/render.mjs` | 圖片原始檔；改字後執行 `PW=$(npm root -g)/playwright node render.mjs` 重出 |

## 照片

所有商品與場景照片為 AI 生成示意圖（Canva），已在頁面標註「示意圖」。正式對外前建議逐張換成實拍：同檔名覆蓋 `img/` 與 `img/src/` 後重出社群圖即可。Canva 設計「卯很多影像素材」保留全部原圖。

## 數字來源

- 售價、套餐：Partner 365 白皮書（爆款 7 品、A–D 套餐），標示為單店模型參考。
- 食安與營運：品富 2026 公司簡介。
- 開辦預算與試算：股東討論書與 2026/10 確認的條件（全部未稅）。
- 招募區域緯度為約略值，僅作排序與示意。
