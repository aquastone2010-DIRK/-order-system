06 · Commerce Flows

社群如何變成訂單

三條商務流程都從社群起點、以 LINE 或快取GO 收單，數字回到 POS，讓每一則貼文的成效可以被量。

Flow 1 · 明日預購

個人預購自取

  1. 限動「明日菜單開放預購」
  2. 點連結進快取GO 預購
  3. 截單後換算備料量
  4. 尖峰走預訂取餐區

追蹤：預購占比、各貼文帶來的訂單數。

Flow 2 · 部門團訂

下午茶與會議餐

  1. 貼文主打一杯紅與滷味拼盤
  2. 部門窗口私訊或 LINE 下單
  3. 確認份數、取餐時間與地點
  4. 出餐並回傳收據

追蹤：團訂筆數、平均份數、回購率。

Flow 3 · 招商轉換

從看到菜到加入

  1. 商品貼建立信任，招商貼說明條件
  2. 個人檔案連結到官網試算
  3. LINE 洽談、預約三天見習
  4. 當面洽談、資格審核、簽約

追蹤：加 LINE 數、見習預約數、洽談數。

08 · Rules

發文規範

不能寫、不能拍

  • 不寫收益承諾或回收期（公平交易法第 21 條）。
  • 不公開業主名稱與上游條件，只寫區域與品類。
  • 科技廠區內不拍攝、不打卡；素材在廠外、中央廚房、逢甲基地拍。
  • 健康文案只寫可驗證數字，不寫減重、降血糖、排毒（食安法第 28 條）。
  • 廣告避免寫成徵才，以免被歸入就業類廣告。

一定要標

  • 商品照片為示意圖；實拍照到位後逐張替換。
  • 售價為單店模型參考，園區櫃位依場域另訂。
  • 費用一律標未稅；條件以正式合約為準。
  • 街邊店標準店、旗艦店費用另洽。
  • 餃一局、卯剛好標「商標檢索中」直到核准。
