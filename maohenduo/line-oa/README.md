# 卯很多 LINE 官方帳號（OA）管理設計

一個官方帳號同時管兩群人：**想加入的潛在夥伴**（招商）與**已簽約的經營夥伴**（營運）。
圖文選單沿用六格便當：上排綠色、下排橘色，中間下格是主行動。

> 目前網站上的 LINE（ID `abingo2025`，QR 指向 `https://line.me/ti/p/ufL_knmKC9`）是個人帳號。
> 官方帳號開通後會有自己的 `@` 開頭 ID，屆時把網站的 QR 與連結換成官方帳號的。

## 四、名單標籤（對應網站的 8 步流程）

每位好友只掛一個「階段」標籤，加上需要的「屬性」標籤。

**階段**：`01 新名單` → `02 已回覆資料` → `03 已見習` → `04 當面洽談` → `05 資格審核` → `06 揭露書已提供` → `07 已簽約` → `08 已開幕`；另有 `暫不適合`。

**屬性**：`意向：六格品牌`、`意向：一二線品牌`、`意向：街邊店`、`區域：竹科／銅鑼／中科／精密／嘉科／南科／醫院`、`意向：麵食櫃`、`意向：四餐櫃`、`資金：90 萬以下／90～120／120～150／150 以上`、`有發票`、`有食品業者登錄`。

規則：
- 新名單 48 小時內必須有人回覆並貼上第一個屬性標籤。
- `05 資格審核` 前不提供業主名稱與上游條件附表。
- `07 已簽約` 後改用夥伴選單（第二階段自動切換；第一階段先手動加進夥伴群組）。

推播事件：上游入帳 → 通知預計撥款日；撥款完成 → 通知金額；物料費餘額低於 3 萬 → 提醒補款；稽核結果出爐 → 通知改善事項。

## 六、群發節奏

| 對象 | 頻率 | 內容 |
|---|---|---|
| 全部好友 | 每月 2 則 | 新櫃位開放（只寫地區與品類）、見習梯次 |
| `03 已見習`～`05 資格審核` | 依進度個別訊息 | 洽談時間、需準備文件 |
| 簽約夥伴 | 每檔期開始前 1 則 | 檔期主打、素材下載 |

群發會用掉方案內的訊息則數，回覆使用者的訊息不計入；免費與付費方案的則數上限請以 LINE 官方最新公告為準。

## 七、上線檢查清單

1. 申請 LINE 官方帳號並完成認證（藍盾）。
2. 後台「圖文選單」選大型 6 格版型，上傳 `richmenu-guest.jpg`，依第二節設定 6 個動作。
3. 設定加入好友歡迎訊息與第三節的關鍵字自動回應。
4. 建立第四節的標籤。
5. 把網站上的 LINE QR、連結、浮動按鈕換成官方帳號。
6. 第二階段：開啟 Messaging API、設定 Webhook，用 `richmenu-*.json` 建立兩組選單並依標籤切換。
